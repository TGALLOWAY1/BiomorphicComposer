# Grouping-cost measurement for the sample

Output of `biomorphic grouping work/IMG_2295 --map samples/IMG_2298.png` on this branch: how many gestures the review UI, as built, needs to assemble each chunk of the artist's hand-made map. `grouping_report.md` / `grouping_report.json` are verbatim; `grouping_sheet.jpg` is a compressed copy of the PNG the command writes.

Re-run with `biomorphic ingest samples/IMG_2295.jpeg` followed by the command above to regenerate the full-resolution files in `grouping_out/`.
